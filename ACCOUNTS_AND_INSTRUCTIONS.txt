2. ЖОБАНЫ ІСКЕ ҚОСУ НҰСҚАУЛЫҒЫ (ЗАПУСК ПРОЕКТА)
=======================================================

Жоба 3 бөліктен тұрады: Бэкенд, Веб Фронтенд, Мобильді қосымша. 
Барлығын іске қосу үшін 3 бөлек терминал (Command Prompt немесе VS Code терминалы) ашыңыз.

--- 1-ТЕРМИНАЛ: БЭКЕНД (Node.js) ---
1. Терминалды ашып, бэкенд папкасына кіріңіз:
   cd c:\Users\User\OneDrive\Desktop\Project\backend
2. Тәуелділіктерді (пакеттерді) орнату (егер орнатпаған болсаңыз):
   npm install
3. Серверді іске қосу:
   npm run dev
*Сервер http://localhost:5000 портында іске қосылуы керек.

--- 2-ТЕРМИНАЛ: ВЕБ ФРОНТЕНД (React/Vite) ---
1. Жаңа терминал ашып, фронтенд папкасына кіріңіз:
   cd c:\Users\User\OneDrive\Desktop\Project\frontend
2. Тәуелділіктерді орнату:
   npm install
3. Сайтты іске қосу:
   npm run dev
*Сайт http://localhost:5173 портында ашылады.

--- 3-ТЕРМИНАЛ: МОБИЛЬДІ ҚОСЫМША (Flutter) ---
1. Үшінші терминалды ашып, мобильді папкаға кіріңіз:
   cd c:\Users\User\OneDrive\Desktop\Project\frontend\prom_spec_mobile
2. Эмуляторды (Android эмулятор) іске қосыңыз немесе телефоныңызды USB арқылы жалғаңыз.
3. Қосымшаны іске қосу:
   flutter run
*Қосымша телефоныңызға/эмуляторға орнатылып, ашылады.
